# Social posts

LinkedIn/social drafts that accompany blog articles, one `social/<slug>.md` per
`posts/<slug>.md`. Generated by the `/create-posts-from-article` skill.

These are drafts for the OpenTeams company account, not published content. This directory sits
outside `posts/`, so the WordPress publish workflow never ingests it. Pick an option, edit it,
and post it manually after the article goes live.
