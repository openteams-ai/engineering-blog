The hardest part of adopting AI tools is often not finding them. It is deciding which ones are worth building around and how to run them safely in production.

The open-source AI ecosystem now has more LLM and agent tooling than most teams can reasonably evaluate.

Once a tool is selected, engineers still need to solve reproducibility, dependency management, and sandboxing challenges underneath it.

What if you could learn directly from engineers dealing with these tradeoffs in production?

The OpenTeams engineering blog is written by maintainers from the open source Python and Jupyter ecosystem, sharing how they evaluate AI tooling and operate it reliably in real environments.

Current topics include:
• Designing AI agents that are safe to run on real workloads
• Choosing and evaluating Python tooling for AI, ML, and data workflows
• Working effectively with AI coding assistants
